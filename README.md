# 練習試合マッチメイカー

夏休みの練習試合（フェスティバル形式）の組み合わせを自動生成するツール。

## 構成

| ファイル | 役割 | 公開URL |
|---|---|---|
| `index.html` | 主催者用。マッチメイク本体 | `https://tabatatsu109-netizen.github.io/matchmake/` |
| `entry.html` | 参加チーム用。申込フォーム | `https://tabatatsu109-netizen.github.io/matchmake/entry.html` |

2ファイルは必ず同じ階層に置く（`index.html` が `entry.html` を相対パスで参照するため）。

## 使い方

1. `index.html` を開きパスワード `2001` を入力（`?pw=2001` を付けたURLなら省略可）
2. 日付・コート（面ごとに会場名／使用時間／試合時間／使用カテゴリー）を設定
3. 「申込URLを作る」→ LINEグループに貼る
4. 各クラブが `entry.html` で入力し、出てきた `[申込] …` の行をLINEに返信
5. LINEのやり取りをコピーして「申込の貼り付け欄」に貼り、「取り込む」
6. 「スケジュールを作る」→ 5案から選ぶ → 必要なら「手動で入れ替える」
7. 画像保存 / 印刷 / テキストでコピー

## 仕様メモ

- バックエンドなし。単一HTML＋バニラJS
- 設定の保存／読込はJSONファイルのダウンロード・アップロード
- スケジューリングは時間の重なりで判定するため、面ごとに試合時間や間隔が違ってもよい
- 各案は乱数リスタート220回×5種の重み付けから最良解を選択
- 時刻は「初戦KO」「最終KO」で扱う（終了時刻ではない）
- 同一クラブ同士は対戦しない。A/B/C のランクは原則同ランク同士
- `index.html` のパスワードはHTMLに直書きのため、ソースを見れば分かる。誤入室を防ぐ程度のもの

## 申込フォーマット

`[申込] チーム名|カテゴリー|人数|初戦KO|最終KO|希望本数|責任者|連絡先|備考`

2チーム分（A・B）で申し込むと、`クラブ名+カテゴリー+A` `…+B` の2行が生成される。
