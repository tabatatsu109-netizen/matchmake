# 練習試合マッチメイカー

夏休みの練習試合（フェスティバル形式）の組み合わせを自動生成するツール。

## 構成

| ファイル | 役割 | 公開URL |
|---|---|---|
| `index.html` | 主催者用。マッチメイク本体 | `https://tabatatsu109-netizen.github.io/matchmake/` |
| `entry.html` | 参加チーム用。申込フォーム | `https://tabatatsu109-netizen.github.io/matchmake/entry.html` |
| `studio/` | 複数会場・採点つきの上位版 | `https://tabatatsu109-netizen.github.io/matchmake/studio/` |

`studio/` は `index.html` `app.js` `score.js` `wizard.js` の4ファイルを同じ階層に置く。
JSを更新したら `index.html` の `?v=` を必ず上げる（上げないと古いJSが混ざる）。

以前あった `entry_3.html` は `entry.html` に統合して削除した（申込URLは `entry.html` を指すため、
その名前でないと 404 になる）。

2ファイルは必ず同じ階層に置く（`index.html` が `entry.html` を相対パスで参照するため）。

## 使い方

1. `index.html` を開きパスワード `2001` を入力（`?pw=2001` を付けたURLなら省略可）
2. 日付・コート（面ごとに会場名／使用時間／試合時間／使用カテゴリー）を設定
3. 「申込URLを作る」→ LINEグループに貼る
4. 各クラブが `entry.html` で入力し、出てきた `[申込] …` の行をLINEに返信
5. LINEのやり取りをコピーして「申込の貼り付け欄」に貼り、「取り込む」
6. 「スケジュールを作る」→ 5案から選ぶ → 必要なら手直し
   - チーム名を押すと、その1チームだけ他チームに差し替えられる（「－ この枠を空きにする」も可）
   - 空き枠の「＋ 試合を入れる」でその場に1試合足せる
   - どちらも「この時間に出せる」チームを上に、出せないものは理由つきで下にまとめて表示する
     （KO可能時間の外／すでに出場中／対象カテゴリー外／カテゴリー差が範囲外／ランク違い／
     「対戦しない」と指定／同じクラブ）
   - カードのドラッグ／タップ2回で試合ごと入れ替え、「手動で入れ替える」で全枠をプルダウン編集
7. 画像保存 / 印刷 / テキストでコピー

## 仕様メモ

- バックエンドなし。単一HTML＋バニラJS
- 設定の保存／読込はJSONファイルのダウンロード・アップロード
- スケジューリングは時間の重なりで判定するため、面ごとに試合時間や間隔が違ってもよい
- 各案は乱数リスタート220回×5種の重み付けから最良解を選択
- 時刻は「初戦KO」「最終KO」で扱う（終了時刻ではない）
- 同一クラブ同士は対戦しない。A/B/C のランクは原則同ランク同士
- **できるだけ色々なクラブと当たるようにする**。同じカード（チーム対チーム）の重複だけでなく、
  「同じところと2本目か」をクラブ単位で見て減らす。`甲府A`／`甲府B` のようなA・B参加や、
  `デソーニョU15`／`デソーニョU13` のようなカテゴリー違いも1つのクラブとして数える
  （数えるときだけの判定で、U15対U13の対戦自体は今まで通り組める）
- **ペア単位で対戦の可否を指定できる**（「対戦してよい組み合わせ」）。左でチームを選び、
  右で相手ごとに「対戦する／しない」を切り替える。指定した分だけ `PAIROV` に持ち、
  空なら今までどおりランク・カテゴリーのルールだけで判定する（＝既存の挙動は変わらない）
  - 「しない」＝ そのペアを完全に除外する
  - 「対戦する」＝ ランク違い・カテゴリー差の制限より優先する。減点も「ランク違い」
    「カテゴリー差」のカウントもしない（主催者が承知の上で組んだ扱い）
  - 同じクラブ同士は「同じクラブ同士の対戦＝禁止」の設定中はロックで変更できない
  - 左側の数字は相手候補の数。1以下なら黄色で警告する（本数不足の予兆）
  - 保存/読込はチーム名で持つ（行の並び替えや再取り込みでも保持される）
- 効き具合は設定「対戦相手のばらけ」で変更可（なるべく／できる限り／気にしない）。
  「気にしない」は従来どおりの挙動。相手クラブが少ない場合は重複を避けられないので、
  その場合は「同じクラブと複数回あたるチーム」として画面に出す
- `index.html` のパスワードはHTMLに直書きのため、ソースを見れば分かる。誤入室を防ぐ程度のもの
- `entry.html` の `let MIN` は、開催情報（`?m=` など）を読む処理より**前**に宣言しておくこと。
  後ろに置くと `m=` 付きのURL（主催者が発行する形）で `ReferenceError` になりフォーム全体が止まる

## 申込フォーマット

`[申込] チーム名|カテゴリー|人数|初戦KO|最終KO|希望本数|責任者|連絡先|備考`

2チーム分（A・B）で申し込むと、`クラブ名+カテゴリー+A` `…+B` の2行が生成される。

## マッチメイク Studio（studio/）

1日用の `index.html` は残したまま並走させる上位版。開催の形が変わっても組めるようにしたもの。

### 1日用との違い

| | 1日用 | Studio |
|---|---|---|
| 会場 | 1つ（面ごとに名前は付く） | 複数。**会場間の移動時間**を考慮する |
| 連戦 | 全体設定のみ | **チームごとに「連戦OK」**（早く帰りたいチーム用） |
| 組む前 | なし | **理論上限のチェック**（物理的に組めるかを先に出す） |
| 結果 | 件数の表示のみ | **総合スコアと6指標＋指摘リスト**（押すと該当試合へ飛ぶ） |
| 開催の形 | 固定 | **テンプレート**（練習試合／フェスティバル／合宿／リーグ戦） |

### 設計思想

- **ハードルールは減点ではなく「公開できません」**。当日に成立しない配置（同時刻2試合・KO時間外・
  対象カテゴリー外・同クラブ・移動が間に合わない）が1件でもあれば、総合スコアを出さずに赤で止める。
  スコアが何点でも当日ダブルブッキングが1件出た時点で失敗だから
- **達成可能な水準を実測して基準にする**。机上の理論値ではなく、実際に生成器を回して到達できた
  水準（最大本数・最小連戦数）を基準に採点する。これをやらないと「相手が足りないだけ」なのに
  低い点が出て、主催者のせいに見えてしまい信用を失う
  - 本数充足：相手側の希望本数も埋まる分を差し引く
  - 相手の多様性：そもそも相手クラブが少なければ繰り返しは数えない
  - 連戦：枠数が足りず必ず連戦になる分は数えない
- **総合は加重平均だが、必ず最低点の指標を併記する**。平均だけだと致命傷が隠れるため
- **重みは開催の形ごとに変える**（`score.js` の `WEIGHTS`）。しきい値は 85以上=緑 / 65以上=黄 / 未満=赤

### 指標

| 指標 | 見ているもの |
|---|---|
| 本数充足 | 希望本数の消化率（届かないのが物理的な理由なら減点しない） |
| カテゴリー適合 | 学年差が設定の範囲を超えた試合数 |
| 相手の多様性 | 同じクラブと2本目以降になった数。A・Bやカテゴリー違いも1クラブと数える |
| 待ち時間 | 試合と試合のいちばん長い空き。1日いること自体は減点しない |
| 連戦 | 続けて2本入った件数（連戦OKのチームは除外） |
| 会場移動 | 会場をまたぐチームの割合。間に合うかどうかはハードで別途担保 |
| 希望反映率 | 「必ず当てる」と指定した組が実際に組まれた割合（指定が0件なら出さない） |

### まだ入っていないもの

複数日・飛び石開催、チームの参加日、期間通算の多様性、確定した試合のロックと部分再生成。

### 手を入れるときの注意

- `score.js` は画面に触らない純粋な計算だけを置く。生成器と診断の両方から使うため
- 生成の探索中（220回×5案）は `quickCost()` の軽い計算を使い、重い `diagnose()` は各案の代表1つにだけかける。
  ここを間違えると生成が数倍遅くなる
- 1日用ツールの保存JSONは、会場を持たないので「1会場」として読み込む（後方互換）

### イレギュラー（特記）

現場の事情はチーム単位で来る。自由文で聞いても解釈も反映もできないので、
**よくあるイレギュラーを選択肢（チップ）にした**。参加チームの表の「特記」から開く。

| チップ | 追加入力 | 効き方 |
|---|---|---|
| 遅れて到着 / 早く帰る / 午前のみ | 時刻 | 初戦KO・最終KO |
| **スタッフ〇名（同時開催不可）** | 人数 | **ハードルール**。同じクラブが同時にその数までしか試合できない |
| **上の学年ともOK / 下の学年ともOK** | 何学年まで | チーム別のカテゴリー許容 |
| 2面同時に出せる / 連戦してもよい | — | 既存の dual / burst |
| その他 | 自由記述 | **生成には効かない**。印刷の「チームからの連絡」に出る |

決めごと

- **「上の学年ともOK」は片側の申告だけで成立する。** 両者の同意を求めると入力が倍になり使われなくなる。
  ただし相手が「対戦しない」と明示していればそちらが優先
- **`staffLimit` はクラブ単位。** 同じクラブのチームで値が違えば最小値を採る。
  クラブの自動判定を誤ると制約が効かないので、選んだときに**同じクラブの他チームを画面に列挙して確認させる**
- 「スタッフ〇名」と「2面同時」は矛盾する。同時に指定できないようにし、スタッフ側を優先する
- 「その他」は生成に効かない。効くように見せると次から誰も使わなくなるので、入力欄の直下に常時明示する

### 対戦してよい組み合わせ（3状態）

押すたびに **対戦する → 必ず当てる → しない → ルールどおり** と巡回する。
「必ず当てる」はハードにはせず強い加点で寄せ、結果は**希望反映率**として採点に出す。

### 質問に答えて設定する（wizard.js）

全体のことだけを5問聞く（開催の形／日付と人数制／会場数／面と時間割／対戦の決まり）。
**チームは表で入れる。**20チーム分を質問形式にすると修正が地獄になるため。
ウィザードは入口、表は編集の場で、どちらも同じデータを指す。

入力のたびに LocalStorage（`mmstudio:draft`）へ自動保存し、次回は「前回の続き」から再開できる。

### 手を入れるときの注意（追記）

- **カテゴリー判定は `catOK()` の1本に集約してある。** 生成器と採点で別々に判定すると
  「生成では通したのに採点で減点」という食い違いが出る
- `catOK()` と `staffFree()` は内側ループ（220回×5案×枠×ペア）から呼ばれる。
  カテゴリー判定は `cfg.catM` に、クラブは整数に前もって置き換えてある。
  ここでクラブ名の正規表現（`clubOf`）を毎回走らせると、16チームで 5秒 → 7秒 に落ちる
- スタッフ制約の判定は**申告があるときだけ**動かす（`anyLimit`）

### リーグ戦（総当たり）

**専用の仕組みは作らず、既存の生成器に載せている。**
「この組み合わせで設定する」を押すと、総当たりのカードを全部「必ず当てる」として登録し、
各チームの希望本数を「グループの人数−1」に、同じカードの上限を1回にそろえる。
あとは通常どおり「スケジュールを作る」を押せばよい。

- グループ分けは カテゴリーごと／カテゴリー＋ランクごと／全チームで1つ の3通り
- **周回数は1周か2周（ホーム＆アウェー）を選べる。** 2周なら希望本数は「（人数−1）×2」、
  同じカードの上限は2回になる
- 同じクラブ同士は（禁止設定なら）カードから除く
- 枠が足りなければ、設定する前に「◯試合ぶん足りません」と出す
- 結果は**星取表**で見せる。組めたセルは時刻（2周なら2つ）、足りないセルは「あと◯本」

「必ず当てる」は本数を持つ（`'want'`＝1本／`'want2'`＝2本）。手で指定する分は常に1本で、
2本になるのはリーグ戦の2周だけ。採点の希望反映率も件数ではなく**本数**で数える。

こうすると採点（希望反映率）も手直し（差し替え・追加）もそのまま使える。
別経路の専用スケジューラを持つと、二重メンテになるうえ手直し機能を作り直すことになる。

### そのほかの決めごと

- **チームのKO可能時間の既定値は、面の使用時間に合わせる**（`defaultWindow()`）。
  最終KOは「使用終了 − 試合時間」＝最後にキックオフできる時刻。
  既存の行は勝手に書き換えず、「時間を面に合わせる」ボタンを押したときだけそろえる
- 時刻の入力は15分単位（`step="900"`）
- **同じカードの上限に「制限なし」（99）**がある。3チームだけの練習試合で使う
- **チーム別タイムライン**：白＝出られない時間、色つき＝試合（面ごとの色）、
  斜線＝試合の間の空き（30分以上なら分数を表示）。連戦・待ち時間・撤収時刻の確認用

### 大会要項をつくる

現場の言い方（「25分ハーフ」「次の試合まで15分」）で答えると、面の設定を計算して入れる。

| 聞くこと | 反映先 |
|---|---|
| 大会名／会場 | `cfgTitle` と会場1つ目の名前 |
| 開門時間 | 進行表のヘッダーに出るだけ（生成には効かない） |
| 1試合目のKO | 全部の面の使用開始 |
| 試合時間（15〜40分ハーフ）＋ハーフタイム | **1試合＝ハーフ×2＋ハーフタイム**を面の「試合」に入れる |
| 次の試合まで（10〜60分） | **開始間隔＝1試合＋この値**を面の「間隔」に入れる |
| 審判割 | なし／主審のみ／主審＋副審2／4人制 |
| 会場注意事項（開門・駐車場・その他） | 進行表の下に「会場からのお願い」として出る |

「この内容で時間割を作る」を押すと、面とチームのKO可能時間まで一気にそろう。
面ごとに違う時間割にしたい場合は、そのあと面の表で直す。

**面の「間隔」は開始から開始まで**（内部の持ち方は変えていない）。
要項パネルだけが「次の試合までの間」で聞き、`1試合＋間` に変換して入れる。

### 審判割

その時間に試合をしていないチームから、**担当回数の少ない順**に割り当てる。
KO可能時間の外にいるチーム（まだ来ていない・もう帰った）は候補から外す。

- 進行表のカードの下に出る。**行そのものを押すと変更できる**（小さなボタンを作らない）
- 出せるチームが足りなければ「副審2 なし」と正直に出す。無理に埋めない
- 手で試合中のチームを入れると「◯◯ はこの時間に試合中」と赤で出る
- 「審判を割り当て直す」で自動割当に戻せる。案を切り替えたときも割り当て直す
- 担当回数は進行表の下にまとめて出す（偏りの確認用）

手で直した審判は、案を変えない限り残る。チームの差し替えでは消えない。
